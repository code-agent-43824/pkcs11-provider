# Состояние проекта

Текущий dev-релиз: `pkcs11-provider-dev-build-18`, обычный GitHub Release со
статусом Latest. GitHub Actions собрал пять архивов для Linux x86_64/ARM64,
macOS Intel/ARM64 и Windows UCRT64 x86_64. На каждой платформе прошли два
прямых unit-теста и загрузка готового модуля через OpenSSL. Скачанные архивы
прошли `SHA256SUMS`; Windows `BUILD-INFO.txt` содержит SHA выпуска.

В Meson остались два прямых unit-теста. Локальная сборка и actionlint прошли;
GitHub Actions подтвердил Address Sanitizer, Shellcheck, REUSE и csbuild.
`imported-softokn`, остальные сценарии с токенами и сквозные тесты удалены
по решению владельца.

Windows UCRT64 цель использует готовый пакет OpenSSL из MSYS2. Перед каждой
сборкой workflow сверяет версию пакета; кэш для версии 3.6.5-1 был
использован повторно. Windows DLL импортирует `libcrypto-3-x64.dll` и
`libwinpthread-1.dll`; они не входят в архив по решению владельца.
Точные цели задаёт `.github/workflows/dev-release.yml`.

macOS сборки используют проверенные SHA-256 пакетов conda-forge OpenSSL
3.6.5 для Intel и ARM64. Обе сборки и архивы загрузились через OpenSSL, а
модули импортируют `@rpath/libcrypto.3.dylib`. В выпуске № 18 оба модуля
содержат только относительный `LC_RPATH` `@loader_path/..`; временного пути
GitHub runner нет. Они подписаны после исправления `LC_RPATH`, проверка
подписи и загрузка OpenSSL прошли на обеих macOS архитектурах. В архиве нет
библиотек OpenSSL по решению владельца. Их `LC_BUILD_VERSION` указывает
минимальную macOS 15.0; изменение цели сборки на 11.0 ожидает проверки в
следующем выпуске.

Коммиты форка после `e5ff476` в `main` имеют автора и коммиттера
`code-agent-43824`. Предыдущие релизные теги сохраняют исходные SHA и
историческую атрибуцию, чтобы сведения о сборке в архивах оставались верными.
