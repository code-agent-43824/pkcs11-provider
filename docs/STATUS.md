# Состояние проекта

Dev-сборка модуля проверена локально на Linux x86_64: `meson compile`, два
unit-теста, загрузка через OpenSSL и компиляция потребителя из распакованного
архива прошли. CI подтвердил Linux x86_64, но выявил ошибки smoke-теста на
Linux ARM64 и пути к p11-kit на macOS Intel. Поправки подготовлены; новый
полный запуск и создание релиза ещё не проверены.

Нативная сборка Windows не заявлена: загрузчик драйвера в `src/interface.c`
использует POSIX `dlopen`/`dlsym`. Готовые архивы предусмотрены для Linux и
macOS; точные цели задаёт `.github/workflows/dev-release.yml`.
