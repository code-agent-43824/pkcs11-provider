# Состояние проекта

Предыдущие dev-архивы опубликованы в предварительном релизе
`dev-8f5a6e4b4ae4-38912595179-1`; четыре архива и `SHA256SUMS` были
проверены. Новая версия после удаления косвенных тестов ожидает проверки
на GitHub runners.

В Meson остались два прямых unit-теста; локально они прошли обычную сборку и
Address Sanitizer. Локальная проверка dev-архива, actionlint и REUSE прошли.
`imported-softokn`, остальные сценарии с токенами и сквозные тесты удалены по
решению владельца. Проверка архива загружает готовый модуль через OpenSSL.

Нативная сборка Windows не заявлена: загрузчик драйвера в `src/interface.c`
использует POSIX `dlopen`/`dlsym`. Точные цели задаёт
`.github/workflows/dev-release.yml`.
