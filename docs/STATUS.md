# Состояние проекта

Dev-архивы опубликованы в предварительном релизе
`dev-8f5a6e4b4ae4-38912595179-1`. Четыре задания GitHub Actions успешно
собрали модули для Linux x86_64/ARM64 и macOS Intel/ARM64. В каждом прошли
два unit-теста, проверка загрузки OpenSSL и проверка потребителя из архива.
Все четыре файла, скачанные из Releases, прошли проверку `SHA256SUMS`;
Linux x86_64 архив дополнительно загружен в локальной среде.

Проверки REUSE и Shellcheck на текущем `main` прошли. Отдельный старый тест
`imported-softokn` упал в Address Sanitizer на одном из промежуточных
коммитов; владелец решает, включать ли его исправление в отдельную задачу.

Нативная сборка Windows не заявлена: загрузчик драйвера в `src/interface.c`
использует POSIX `dlopen`/`dlsym`. Точные цели задаёт
`.github/workflows/dev-release.yml`.
