# Передача работы

Незавершённой работы нет. Выпуск № 23 содержит семь release-архивов;
все прошли `SHA256SUMS`. Windows x86, x64 и ARM64 модули импортируют
только системные DLL и общую с приложением `libcrypto`, без отдельных
DLL MinGW runtime. Подробности и ограничения записаны в `docs/STATUS.md`.
