# Прямые тесты кода провайдера

Meson запускает три unit-теста: декодирование точки EC, разбор URI PKCS #11
и проверку решения о входе по флагам PIN. Все три вызывают функции
провайдера без программного токена и внешних сервисов.

```sh
meson test -C builddir --suite unittests --print-errorlogs
```
